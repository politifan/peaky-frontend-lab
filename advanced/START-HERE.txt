Распакуйте целиком в новую учебную папку. Текущие порядок и критерии — Stepik и START-HERE, DOCX редакции 2 справочные. Отчёт TXT/Markdown достаточен. Локальные программы и задачи Stepik проверяют разные результаты; External Grader не подключён.

Рабочая папка student/lab. Node >=22.12, Python 3.12. npm ci → npm run build. Затем venv и pip install -r requirements.txt.
API: .venv/Scripts/python.exe -m uvicorn server:app --host 127.0.0.1 --port 8000
После сборки основной адрес http://127.0.0.1:8000. Для dev во втором терминале npm run dev; proxy /api идёт на 8000, origin5173 отличается. В Linux/macOS python3.12 и .venv/bin/python, активация не обязательна.
Vite закреплён 7.3.7. Учебная сборка сохраняет полные модули (treeshake=false) и включает минификацию; фактический размер измеряйте по артефакту. Это профиль воспроизводимого стенда, не доказательство оптимального production bundle.

Переход функции в компонент: откройте /?practice=state. Счётчик useReducer уже работает. src/practice/selector.js и editorReducer.js — ученические заготовки, их пустое поведение ожидаемо до вашей реализации.
1. Перенесите собственную solve(data) селектора в selector.js, сохранив export. Компонент хранит items и selectedId, а title вычисляет при render. Выберите запись, измените её title, удалите. Ожидания: новая подпись, затем «Не выбрано». Пустая строка отдельно показывает «(пустая подпись)».
2. После разобранного counter реализуйте editorReducer: edit меняет draft, save копирует draft в saved, cancel возвращает draft к saved, неизвестное событие сохраняет state. Введите первый текст, убедитесь, что saved прежний, сохраните, введите второй и отмените. Поле вернулось к первому. Повторите с пустой строкой и собственными значениями.
3. В диспетчерской выполните реальный запрос и диалог. JSON-функция не доказывает DOM, focus или сеть. Сначала обычный URL, затем ОДИН профиль /?fault=search/outbox/cache/dialog. Функции faults.js намеренно неверны только в назначенном профиле.

Для search: a затем быстро ab, дождитесь обоих ответов; актуальным остаётся ab. Для dialog: editor→confirm→Escape оставляет editor и фокус внутри него; второй Escape возвращает исходную кнопку. Для outbox: одно намерение получает один ключ, потерянное подтверждение и новый процесс не дают второй эффект. Сохраняйте SQLite и localStorage. Порты, процессы и учебные данные фиксируйте в отчёте.

Из student можно запускать lab/.venv/Scripts/python.exe check_examples.py TASK_KEY после установки Playwright/Chromium; в Linux lab/.venv/bin/python. KEY соответствует tasks/KEY.js и examples/KEY.json. Это открытые примеры JavaScript solve, Python только управляет браузером; не полный DOM-экзамен.
